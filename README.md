## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/shvnix/shivansh-panwar.git
```

Move into the project

```bash
cd shivansh-panwar
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
